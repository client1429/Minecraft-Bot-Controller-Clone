✅ Works immediately, no Minecraft server needed
❌ Limited to chat simulation only


OPTION 2: START REAL MINECRAFT SERVER (For Full Features)
-----------------------------------------------------------
1. Download server.jar from https://minecraft.net/en-us/download/server
2. Create folder C:\minecraft-server and put server.jar there
3. Create start-server.bat with:
   java -Xmx1024M -Xms1024M -jar server.jar nogui
4. Run start-server.bat
5. Edit eula.txt (change false to true)
6. Edit server.properties (set online-mode=false)
7. Restart server
8. Run: npm start
9. Connect bot via http://localhost:3000


OPTION 3: CONNECT TO EXISTING SERVER
-------------------------------------
Use an external Minecraft server address instead of localhost.
Example: Your friend's server IP or a public test server

================================================================================
                     CONNECT VIA WEB INTERFACE
================================================================================

1. Start the server: npm start
2. Open browser: http://localhost:3000
3. Enter server details:
   - Host: localhost (or your server IP)
   - Port: 25565
   - Username: YourBotName
4. Click "Connect"

================================================================================
                         TEST CAPTCHA FEATURES
================================================================================

Once connected, test the screenshot and captcha features:

Take screenshot:
    curl -X POST http://localhost:3000/api/screenshot

Solve captcha:
    curl -X POST http://localhost:3000/api/solve-captcha

Send chat command:
    curl -X POST http://localhost:3000/api/bot/command \
      -H "Content-Type: application/json" \
      -d '{"command": "Hello!"}'
